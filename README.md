# 🌱 ふたり家計簿 (PairBudget)
### LINE公式アカウント × LIFF × GitHub Pages × GAS × スプレッドシートによる共同家計簿

同棲カップル・共働き夫婦のための**完全無料（月額0円）**で運用できるスマート共同家計簿システムです。  
「共同カードで私物を買った時の精算」「買い物リスト連動」「月別予算・固定費管理」など、ふたりの生活の摩擦をゼロにする機能を備えています。

---

## 🌟 特徴・コア機能

1. **初期費用・月額サーバー費用が完全0円**:
   - Google Apps Script (GAS) ＆ GitHub Pages ＆ LINE Messaging API（無料枠）で動作。
2. **LINEトークで3秒クイック記帳**:
   - 「スーパー 3200」「立替 1500 日用品」「共同カード 私物 5000 スニーカー」と打つだけで自動分類。
   - 「残金」「振込額」と送るだけで、今月の残高や振込必要額を即答。
3. **「共同カードで私物購入」の自動精算チェッカー**:
   - 振込額 ＝ 基本拠出 (例: 60,000円) ＋ 共同カード私物利用額 − 個人財布での立替額
   - 電卓不要で、月末に共同口座へいくら振り込めば良いかが1円単位で確定。
4. **買い物リスト（買うもの共有 ＆ 支出即時連動）**:
   - LINEで「買う 牛乳」と送信すればリストに追加。
   - LIFF画面でチェックすると「買った！🎉 金額を入力して支出に登録しますか？」と自動連動。
5. **固定費オートパイロット ＆ 月別変動予算**:
   - 家賃・光熱費・サブスクを毎月1日に自動計上。
   - 8月（夏休み）や12月（年末年始）など、月ごとに異なる特別予算を柔軟に設定可能。
6. **プライバシー配慮**:
   - 相手の画面で私物の品目名をマスキング（「私物支出」とだけ表示）する設定が可能。

## 🚀 導入・セットアップ手順（完全ステップバイステップ）

**新規の方**は Step 1 → 6 を順に実施し、レシート読み取りを使うなら Step 7 も行います（所要時間の目安: 約60分）。Step 8 は旧バージョンからの更新用です。

- [ ] Step 1〜5: スプレッドシート・LINE・GitHub Pages・LIFFを用意
- [ ] **Step 6（必須）: 本人確認の設定と夫婦の登録 ← これで初めて安全**
- [ ] Step 7（任意）: レシート読み取り（AI-OCR）

### Step 1: Googleスプレッドシート & GASの準備
1. [Google スプレッドシート](https://sheets.new) を新規作成し、タイトルを「`ふたり家計簿_DB`」などに設定します。
2. 上部メニューの **「拡張機能」 ➔ 「Apps Script」** を開きます。
3. デフォルトの `コード.gs` の内容をすべて消去し、[`backend/Code.gs`](file:///Users/inaoya/Documents/antigravity/AI%20company/pair-budget-app/backend/Code.gs) の中身を丸ごと貼り付けて保存します。
4. エディタ上部の関数選択ドロップダウンから **`setupSpreadsheet`** を選択し、**「実行」** ボタンを押します（※初回のみGoogleのアクセス承認ダイアログが出ますので許可してください）。
   - 実行後、スプレッドシートに戻ると `Transactions` `Receipts` `ReceiptItems` `AuditLog` `ShoppingList` `MonthlyBudgets` `FixedExpenses` `Categories` `Rules` `Config` の全シートと初期サンプルデータが自動生成されます。
5. GASエディタ右上の **「デプロイ」 ➔ 「新しいデプロイ」** をクリックします。
   - 種類の選択（歯車アイコン）: **ウェブアプリ**
   - 説明: `v1`
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（※LINE WebhookやLIFFから通信するため）
   - **「デプロイ」** を押し、発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーしてメモしておきます。
6. **固定費の自動計上トリガーを設定**:
   - GASエディタ左メニューの「トリガー（時計アイコン）」➔「トリガーを追加」
   - 実行する関数: `processMonthlyFixedExpenses`
   - イベントのソース: `時間主導型`
   - タイプ: `月タイマー`（毎月1日午前0時〜1時）で保存します。

---

### Step 2: LINE公式アカウント ＆ Messaging APIの開設
1. [LINE Developers コンソール](https://developers.line.biz/console/) にログインします。
2. プロバイダーを新規作成（例: `ふたりライフ`）。
3. **「Messaging API」** チャネルを新規作成します。
   - チャネル名: `ふたり家計簿Bot`
   - チャネル説明・大業種・小業種を適当に入力して作成。
4. 作成したチャネルの設定画面を開きます：
   - **「Messaging API設定」タブ**:
     - Webhook URL に、Step 1でメモした **GASのウェブアプリURL** を貼り付け、「検証」ボタンを押して「成功」になることを確認後、**「Webhookの利用」をON** にします。
     - チャネルアクセストークン（長期）の **「発行」** を押し、トークン文字列をコピーします。
5. GASに戻り、左メニューの「プロジェクトの設定（歯車アイコン）」➔「スクリプト プロパティ」に以下を追加します：
   - プロパティ名: `LINE_CHANNEL_ACCESS_TOKEN`
   - 値: コピーしたチャネルアクセストークン
6. LINE公式アカウントの管理画面（LINE Official Account Manager）の「応答設定」で、**「チャット」をOFF（またはWebhookを優先）**、**「あいさつメッセージ」と「応答メッセージ」をOFF** に設定しておきます。

---

### Step 3: GitHub PagesでのLIFFフロントエンド公開
1. GitHubで新しいパブリックリポジトリを作成します（例: `pair-budget-app`）。
2. 本リポジトリの `frontend/` フォルダ内のファイル（`index.html`, `css/style.css`, `js/config.js`, `js/app.js`）をアップロード（またはプッシュ）します。
3. リポジトリの **「Settings」 ➔ 「Pages」** を開きます。
   - Source: `Deploy from a branch`
   - Branch: `main` / `root` を選択して **「Save」**。
4. 数分後、GitHub PagesのURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。

---

### Step 4: LIFF (LINE Front-end Framework) アプリの作成 ＆ `config.js` の設定
1. LINE Developers コンソールに戻り、先ほどのプロバイダー内に **「LINEログイン」** チャネルを新規作成します。
2. 「LIFF」タブを開き、**「追加」** をクリックします：
   - LIFFアプリ名: `ふたり家計簿`
   - サイズ: **Full**
   - エンドポイントURL: Step 3で公開した **GitHub PagesのURL**
   - Scope: `profile`, `openid` にチェック
   - ボットリンク機能: `Normal` または `Aggressive`
3. 発行された **LIFF ID**（`xxxxxx-xxxxxx`）と **LIFF URL**（`https://liff.line.me/xxxxxx-xxxxxx`）をコピーします。
4. **【重要】`frontend/js/config.js` に GAS URL と LIFF ID を記入**:
   - `frontend/js/config.js` を開き、`GAS_URL`（Step 1のウェブアプリURL）と `LIFF_ID`（今発行したLIFF ID）を記入して GitHub にプッシュします。
   - これにより、LINEアプリ内で開いた際に自動でLINEログイン＆GAS接続されます（※サーバー側での本人確認の強制には、続く **Step 6 の `LIFF_CHANNEL_ID` 設定**が必須です）。

---

### Step 5: LINEリッチメニューの作成 ＆ 運用開始！
1. LINE Official Account Manager の「トークルーム管理」➔「リッチメニュー」を開きます。
2. 「家計簿ダッシュボードを開く」ボタンのアクションに、Step 4の **LIFF URL** を設定します。
3. パートナーとふたりでLINE公式アカウントを友だち追加します。

### Step 6（必須）: 本人確認の設定 ＆ 夫婦のアカウント登録
> [!CAUTION]
> **この Step 6 まで完了して初めて安全に使えます。** 未設定の間は、安全のためサーバーが「本人確認の設定が未完了」として通信をブロックします（デモ用途で認証なし動作させる場合のみスクリプトプロパティ `DEMO_MODE=true` を設定します）。Step 1〜5 を終えたら、続けて必ず実施してください。
1. **LIFF_CHANNEL_ID を設定**: GASの「プロジェクトの設定」➔「スクリプト プロパティ」に追加します。
   - プロパティ名: `LIFF_CHANNEL_ID`
   - 値: Step 4 で作成した **LINEログインチャネルの「チャネルID」**（LINE Developers のチャネル基本設定に表示される数字のID）
   - （任意）登録時に合言葉を求めたい場合は、スクリプトプロパティ `REGISTER_CODE` に任意の合言葉を設定できます。
   - 設定すると、GASはLIFFのIDトークンをLINEサーバーで検証し、**登録済みの夫婦以外はデータの閲覧・書き込みができなくなります**。
2. **アカウント登録（初回のみ・LIFF画面でワンタップ）**:
   - ご夫婦それぞれがLINEからLIFFアプリを開くと、初回のみ **「初回アカウント登録」画面** が自動で表示されます。
   - **「👨 夫として登録」** または **「👩 妻として登録」** をタップするだけで、検証済みLINEアカウントが安全に紐付けられます（先着で登録され、登録済みの枠は上書きできません。変更する場合はスプレッドシート `Config` シートの `husbandUserId` / `wifeUserId` を直接編集してください）。
3. 以降、すべての追加・編集・削除は **「誰が・いつ」** 操作したかが自動記録されます（支出一覧の「登録/修正」表示、履歴タブの「ふたりの記録帳」）。

> [!IMPORTANT]
> スプレッドシートを直接編集すると、履歴に残らない変更ができてしまいます。家族以外にはシートを共有せず、ご夫婦のGoogleアカウントも「閲覧のみ」で共有する運用を推奨します。`AuditLog` シートは書き換えず、Googleの「変更履歴（バージョン履歴）」と併用すると改ざん検知に有効です。

### Step 7: レシート読み取り（AI-OCR）の設定
1. [Google AI Studio](https://aistudio.google.com/apikey) で **APIキー** を発行します（無料枠あり）。
2. GASのスクリプト プロパティに追加します。
   - プロパティ名: `GEMINI_API_KEY` ／ 値: 発行したAPIキー
   - （任意）`GEMINI_MODEL`: 使用モデル。未設定なら `gemini-2.5-flash`
3. アプリの「＋」➔「レシートを撮影して自動入力」から使えます。

> [!WARNING]
> レシート画像はGoogleのGemini APIに送信されます（当アプリのサーバーには保存されません）。**無料枠では送信内容がGoogleのサービス改善に利用される場合があります**。気になる場合は有料枠（Cloud請求の有効化）をご利用ください。レシートには店名・購入日・購入品が含まれます。カード番号や氏名が写らないよう撮影してください。

### Step 8: すでに旧バージョンを導入済みの方（アップデート手順）
1. **バックエンド更新 ＆ シート追加（最初に実施）**:
   - GASの `コード.gs` を最新の [`backend/Code.gs`](file:///Users/inaoya/Documents/antigravity/AI%20company/pair-budget-app/backend/Code.gs) に丸ごと置き換えて保存します。
   - GASエディタで **`setupSpreadsheet` を必ず一度実行**します（**既存データは消えません**。新しい列・シート `Receipts` / `ReceiptItems` / `AuditLog` だけが追加されます）。
2. **GASの再デプロイ**:
   - 「デプロイ」➔「デプロイを管理」➔ 鉛筆アイコン ➔ バージョン「新バージョン」で **再デプロイ**します（URLは変わりません）。
3. **フロントエンドの更新**:
   - GitHub リポジトリの `frontend/index.html`、`frontend/js/app.js`、および新規追加された `frontend/js/config.js` を最新版に更新し、`config.js` に `GAS_URL` と `LIFF_ID` を記入してプッシュします。
4. **本人確認設定（Step 6）の実施**:
   - GASのスクリプトプロパティに `LIFF_CHANNEL_ID` を追加し、LIFFアプリを開いて夫婦それぞれの初回アカウント登録を行ってください。
   - ※旧バージョンで登録済みの支出は、登録者が「不明」と表示されます。

## 📅 過去の履歴・グラフ・価格検索の使い方
- **過去3年分の閲覧**: 画面上部の月名の左右の矢印で、最大36ヶ月前まで遡れます（予算・振込額・支出一覧すべて月ごとに切り替わります）。
- **月別推移グラフ**: ホームの折れ線グラフで、6ヶ月／1年／3年の支出推移と予算を確認できます。
- **レシート明細のグループ表示**: 支出一覧では店名ごとにまとまり、タップで明細（ー ネギ ¥180 など）が展開されます。
- **価格検索**: 「履歴・固定費」タブの「過去の価格を調べる」、またはLINEで `ネギ いくら` / `価格 豆腐` と送ると、過去の購入価格（直近・最安・平均・最高、お店別）がわかります。レシートを読み取るほど精度が上がります。

## 🔒 セキュリティ＆プライバシー
- 家計データはすべて作成者自身の Google ドライブ（スプレッドシート）内に保存され、当アプリの運営サーバーは存在しません。
- **レシート読み取り（AI-OCR）を使う場合のみ**、レシート画像がGoogleのGemini APIへ送信されます（保存はされません）。無料枠では送信内容がGoogleのサービス改善に利用される場合があります。
- `frontend/js/config.js` に書いたGAS URLはGitHub上で公開されますが、`LIFF_CHANNEL_ID` を設定（Step 6）していれば、登録済みの夫婦のLINEログイン無しではデータにアクセスできません。
- 私物支出の品名マスキングをONにすることで、金額精算の正確性を保ちながら互いのプライベートを守ることができます。
