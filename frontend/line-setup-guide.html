1

LINE公式アカウント ＆ Messaging APIチャネルの準備

LINE Developers コンソールでチャネルを作成します

  1. LINE Developers コンソール にログインします。
  2. ⚠️ 重要ポイント: 既存のLIFFアプリを作成した「同じプロバイダー」を選択してください。
  3. 「新規チャネル作成」をクリックし、チャネルの種類で 「Messaging API」 を選択します。
  4. チャネル名（例: ふたり家計簿Bot）、アプリアイコン、会社・事業者名（個人名でOK）、メールアドレスを入力し、利用規約に同意して作成します。
2

2つのLINEキー（Secret ＆ Access Token）の取得

サーバー通信用の認証キーをコピーします

① チャネルシークレット (Channel Secret)

「チャネル基本設定」タブ ➔ 少し下にスクロールした「チャネルシークレット」の値をコピーします。

② チャネルアクセストークン (長期)

「Messaging API設定」タブ ➔ 一番下の「チャネルアクセストークン（長期）」の右側にある 「発行（Issue）」 ボタンを押し、生成された長い英数字の文字列をコピーします。

3

Vercel に環境変数を設定して再デプロイ（Redeploy）

サーバーにLINEキーとGeminiキーを登録します

Vercel ダッシュボード ➔ 家計簿プロジェクト ➔ Settings ➔ Environment Variables を開き、以下の3つの環境変数を追加します：

LINE_CHANNEL_SECRET

Step 2で取得したチャネルシークレット

LINE_CHANNEL_ACCESS_TOKEN

Step 2で発行したチャネルアクセストークン（長期）

GEMINI_API_KEY

Google AI Studioで取得したGemini APIキー（設定済みならOK）

環境変数を保存したら必ず「Redeploy」してください！

Vercel の Deployments タブ ➔ 最新のデプロイ右側の「…」➔ 「Redeploy」 を実行することで、新しい環境変数がサーバーレス関数に反映されます。

4

LINE側のWebhook設定と応答設定の切り替え

LINEとVercelサーバーを接続します（最重要ステップ）

① Webhook URL の登録

LINE Developers の 「Messaging API設定」 タブ ➔ Webhook URL に以下を入力して「更新（Update）」を押します：

「Webhookの利用（Use webhook）」トグルを ON（緑色） にします。
「検証（Verify）」ボタンを押し、「成功（Success）」 と表示されることを確認します。
② LINE公式アカウント 応答設定（二重応答の防止）
ここを設定しないと定型文とAIが2重送信されます！

LINE Developers の「Messaging API設定」タブ内のリンクから 「LINE Official Account Manager」（または LINE公式アカウント管理画面）を開き、右上の「設定」➔ 「応答設定」 を以下のように変更してください：

応答メッセージ（自動応答） ➔ OFF（無効）
Webhook ➔ ON（有効）
5

実際にLINEトークからテスト送信してみましょう

LINE Official Account Manager ➔ 右上「設定」➔ 「アカウント設定」➔「チャット設定」➔「グループ・複数人トークへの参加を許可する」を ON にしてください。これで、ふたりの共有LINEグループにこのBotを招待して、2人でレシートや買うものを共有できるようになります！
